# multi-class-challenge-mkrs-GS


Makers challenge 

copy and paste the below in to your terminal to create a venv and run the tests

```bash
git clone https://github.com/chris-adams-5/multi-class-challenge-mkrs-GS.git
echo venv_mulit_class_chal > .gitignore
python3 -m venv venv_multi_class_chal
source venv_multi_class_chal/bin/activate
pip install --upgrade pip
pip install pytest
pytest -xv
```
